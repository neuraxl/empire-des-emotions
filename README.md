# L'Empire des émotions — page de présentation

Page de présentation de l'offre de marketing émotionnel de **Roger Savard** (Sav'art, Québec) :
capsules vidéo émotionnelles, séries, forfaits mensuels et jingles pour les commerces.

- Accroche : « Je ne vends pas des vidéos. Je vends ce que vos clients ressentent. »
- Six univers : Désir, Beauté, Sérénité, Imagination, Sécurité, Espoir.
- Forfaits de lancement : capsule 125 $, série découverte 375 $, forfait mensuel 250 $/mois, jingle 175 $, identité visuelle 150 $.
- Plan complet : `../plan-direction-a-adaptee.pdf` (dossier local, hors dépôt).

Site statique : `index.html`, `sitemap.xml`, `robots.txt`, aucune dépendance.
L'aperçu de partage (Open Graph) utilise la vignette YouTube de la capsule intégrée.
Le formulaire de demande envoie les demandes par courriel via FormSubmit (service gratuit,
sans compte) vers savardrjr@gmail.com — surveillé par le clone dédié.
